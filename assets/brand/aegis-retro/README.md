## Use

- Horizontal dark and light logos: project headers, documentation, presentations and footers.
- Stacked logo: covers and square announcements.
- Colour emblem: overlays; the outside is transparent, but the dark interior is retained. Check against the intended background before use.
- Ivory and orange emblems: simpler treatments with backgrounds already included.
- Social avatar: profile pictures; preview the platform's crop before publishing.
- App icon artwork: a visual source for future app-icon integration; it has not been installed or added to the app asset catalogue.
- Banner and poster: promotional layouts using “Your Aegis. Your Mac.”

These are PNG raster assets, not vector masters or print-ready separations. Generated variants have small geometric and texture differences; use the approved reference as the source of truth when preparing a consistent vector master. The transparent colour emblem has textured edges, so prefer the background-backed marks for small placements. Keep proportions, leave clear space, and avoid stretching. Palette hex values in prompts are design targets rather than exact pixel guarantees.

Created with the built-in image generation tool. The final prompt directions and reference are recorded in `prompts.json`. No external publishing or changes to the app's current icon were performed.
