# Handoff — Claude — issue #16 — 2026-10-08

## What changed
- Integrates Codex's Mail reader (PR #34; its commits are on this branch) with current main.
- `mail_reader.py`:
  - **Header defects no longer drop a message.** Real mail has many minor ones, e.g. an unquoted `J. Sample` display name. When Python can't parse a header at all (3.9 raises for some), the raw text stands in.
  - **Time fallbacks:** a malformed `Date` falls back to the newest `Received` hop, then to the index's `date_received`.
  - **Older layouts:** `deleted` is optional, falling back to bit 1 of `flags`. The date epoch is detected (Unix on modern macOS, since 2001 on older builds). Both findings come from #37.
  - **HTML:** `<body>` closes an unclosed `<head>` or `<title>`, so the body isn't lost.
- `test_mail_reader.py`: two tests now expect the message kept instead of dropped; four new tests.

## Decisions made (and why)
- Keeping a message with a raw sender or ID beats losing it. Recall matters more than perfectly parsed headers, and nothing is acted on.
