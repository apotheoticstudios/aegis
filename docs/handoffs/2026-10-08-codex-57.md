# Handoff — Codex — issue #57 — 2026-10-08

## What changed
- Addressed Claude's review of the uncommitted Emlx parser in `codex/57-emlx-parser`.
- Contract addition: `MailMessage.encrypted` exposes detected encrypted MIME parts; `attachmentOnly` indicates absence of non-attachment plain/HTML parts. Empty text parts count as present. Both booleans can be true; the reader should give the encrypted flag precedence, as Python does.
- Received fallback now parses only the first header's date after its last semicolon. An invalid topmost date falls back to the index, even if a lower header is valid.
- Failed non-UTF-8 whole-buffer decoding salvages at most 64 KiB and replaces the remaining bytes with one U+FFFD. Valid whole-buffer decoding and linear UTF-8 replacement retain the entire body.
- Split date, recipient, MIME and HTML functions, moved the HTML entity table to a separate file, grouped existing tests into extensions, and documented intentional replacement decoding to clear all lint warnings.
- Added five regression tests covering flags, empty/hidden text, clock-skewed Received hops, bounded salvage and valid large bodies.
