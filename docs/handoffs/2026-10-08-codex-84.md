## Decisions made (and why)
- Ingest only upserts records and stores checkpoints atomically; it never deletes anything, regardless of checkpoint completeness or missing source records. Notification dismissal and windowed/incremental scans preserve event history. Older checkpoints cannot regress the stored cursor. Events are removed only by the retention horizon, with kept brief citations protected and FTS synchronized. Mirroring Messages/Mail deletions remains an undecided privacy policy.
- Removed whole-source reconciliation, persistent memberships and ingest seen tracking. The unreleased v1 schema records source directly on occurrences/reminders instead; no shared AegisKit contract was changed.
- Schedule reconciliation is explicit: `reconcileOccurrences(source:window:seen:)` removes only that source's unseen occurrences overlapping a half-open window (including zero-duration items inside it). `reconcileOpenReminders(source:seen:)` removes only that source's unseen open reminders, preserving every completed reminder for completion-window queries. Each call uses one transaction and is safe on empty stores. Collectors call only after ingesting all pages of a complete scan of exactly that source/window or all of that source's open reminders; `seen` spans the entire scanned scope. A temporary schedule-only seen set avoids SQLite bind limits.
- Regression coverage includes complete batches missing events, dismissed notifications surviving reopening and FTS search, occurrence overlap/window boundaries and source isolation, completed reminders (including unknown completion time), empty stores, and rollback after an SQLite FAIL trigger partially applies a deletion.
- Capture time is the available version stamp; equal timestamps keep the first version. Observations deduplicate by route + source record ID, retaining earliest capture time.
- StoredBrief has no completion flag. Accept a validated finished Brief with nonempty inputRevision and existing citations; reject incomplete/invalid input transactionally. Unavailable source coverage remains valid. History orders by storedAt, with insertion ID as a tie-breaker, default last 30.
- Half-open windows; protocol reads cap at 1,000, with paging overloads. Paging assumes records remain unchanged during traversal. Indexed contract times use JSON's microsecond precision so keyset traversal cannot repeat or skip fractional-time rows.
- No shared contracts, dependency versions, STATUS changes, commits, pushes or PR creation.
