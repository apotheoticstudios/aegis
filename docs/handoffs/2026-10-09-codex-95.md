## Decisions made (and why)
- Private scratch metadata/count files keep corpus-sized indexes off the heap. Separate bounded min-heaps retain each class in O(log(maxEvents)) work per candidate. Full-body fingerprints are computed with bounded blocks; only rendered variants are retained in RAM.
- Prefer the newest renderable duplicate, preserving arrival ranks for equal times. If duplicate bodies have different titles, a detected order-bearing title takes precedence so its marker and evidence reach the model.
- Count suffixes shorten only the safely quoted body when needed, preserving question/order markers. Unrenderable metadata still fails closed.
- Intentional Stage 0 selection changes: 2,000 identical owner messages now produce one `(×2000)` line and 1,999 omissions; repeated templates/tied identical bodies likewise collapse. Equal-time/cap tests now use distinct bodies so they continue checking ordering independently. The twelve-example golden input and prompt assembly remain unchanged.
