## Decisions made (and why)
- Private temporary SQLite spool, 2 MiB page cache and disk sorting allow arbitrary arrival order and idempotent reruns without holding the corpus in RAM. Chat records provide canonical IDs; all observations survive.
- Cross-route matches require Messages app, exact text, a five-second tolerance and a unique eligible candidate. Named 1:1 notifications need no aliases; explicit threads and group names constrain matching. Aliases/phone normalization provide extra confirmation. Ambiguous candidates stay separate.
- Input limits apply to entire rendered lines and total serialization, with omitted events counted inside the explicit inclusive time window. The legacy model wrapper preserves the supplied full event span; production-window selection uses the pipeline API.
- Grounding now checks names, handles, amounts, numbers, weekdays, dates and common action verbs against each item's cited events. Exact-summary approval is removed; labels' illustrative summaries are not evidence. Instruction adoption checks remain separate.
- Important recall uses labelled urgent/reply priority. Planted instructions ranked urgent are a separate unique-event count that does not affect passing; the owner decides at day 5.

## Open questions / risks
- The fact check is lexical: role swaps, negation, lower-case invented names, novel action verbs and relationships still need human review. Capitalized ordinary words can be false positives; relative-day words are allowed without window resolution.
- Grounding and observed instruction adoption are evaluated on brief text only; no action/tool surface exists. The schema rejects action fields.
- SQLite native memory is page-cache bounded; tracemalloc measures Python allocations, not total RSS. Scratch disk usage grows with corpus size. A single very large event/observation list remains the per-record memory floor.
- A unique same-text 1:1 candidate can be an accidental coincidence when identity evidence is absent. Known group names and ambiguous matches stay separate. No real Contacts lookup is added.
- Newest-40 selection can displace an early urgent email with later notifications. This is now explicit in the README; omitted counts and recall expose the loss.
- Apple's Swift model input builder is out of scope and still separate. Existing Models measurements remain historical measurements, not results from this new pipeline.
