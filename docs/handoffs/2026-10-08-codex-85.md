# Handoff — Codex — issue #85 — 2026-10-08

## What changed
- Added documented portable contact snapshots, a sender-handle index, resolution results and event enrichment under AegisKit/Identity.
- Added synthetic XCTest coverage for AU/international phones, exact short codes/brands, emails, distinct-ID ambiguity, empty names, outgoing/handleless events, text independence, repeat resolution, contract validation and 10,000 contacts with 30,000 handles.

## Decisions made (and why)
- Resolution uses only senderHandle; sender, title and body never supply identity. Outgoing and handleless events remain unchanged; other events replace stale contact and ambiguity results.
- AU national numbers receive country code 61. Explicit international numbers and bare country-coded numbers match. Other default regions do not guess a national country code. Short codes and brands retain exact spelling after outer trimming and tel: removal.
- The issue's 0480027043 example has ten digits, so it follows the AU mobile rule; actual five/six-digit short codes match exactly.
- Duplicate handles and snapshots with one contact ID count once. Empty IDs are excluded so resolved events remain valid. Blank names use the queried raw handle.
- New public identity types are the API requested by #85; existing Event v0.2 and IPC contracts are unchanged. No dependencies, architecture, privacy or safety system changes.
- Work ran entirely in the aegis cloud environment. The host's Swift 6.0.3 cannot build current GRDB; full checks use CI's Swift 6.2 container. Lint tools and temporary assets remain outside the repository.
