## Decisions made (and why)
- Keep selected rows, paths, and duplicate IDs in a private temporary SQLite database, mirroring Python's bounded-memory staging. One FileManager enumeration per nonempty read; no walk or file open for an empty SQL selection.
- Join available subjects, addresses, and mailboxes with LEFT JOIN; From and Subject headers remain authoritative. Minimal/older layouts can omit the metadata tables and conversation column.
- Treat `.emlxpart` as a partial download, alongside `.partial.emlx`; prefer `.emlx` regardless of enumeration order.
- Set direction to incoming, extract senderHandle with the existing emailAddress(in:) rule, and label index date fallback as received.
- Specification clarification: duplicate_message_id problems retain the Message-ID in their note because the Python reader and expected/problems.json require it for exact parity. Other per-message defects carry row IDs only; framing notes are count/truncate. Nothing logs these values.
- No changes to existing shared contracts or dependencies.
