# ChatGPT image and asset prompts

For `type:asset` issues. Aegis's look: hard-edged sci-fi HUD, translucent glass panels over a dark grid, chamfered corners, thin rules, mono readouts, an orbital hex "reactor" core. Accent cyan #4FD1E8 or amber #FF9A2E on near-black #02060B. No rounded "friendly" shapes, no gradients-on-white, no real company logos or film characters.

## App icon

```
Design a macOS app icon for "Aegis", a private AI assistant. A glowing hexagonal reactor core with fine orbital rings, cyan (#4FD1E8) light on a near-black (#02060B) background, hard sci-fi HUD style, crisp geometric lines, subtle depth. It must read clearly at 16×16 px as well as 1024×1024. No text, no letters, no existing logos or film imagery. Square canvas, 1024×1024, centred, generous margin.
```

## Menu bar icon studies

```
Draw a sheet of 4 monochrome menu bar icon variants (template images) for a sci-fi assistant: a hexagon with an inner core. States: nominal, waiting (filled core), urgent (halo), fault (broken outline). Pure black on transparent, 1 px strokes at 22×22 px, pixel-crisp.
```

## Reactor texture / concept frames

```
Create a still concept frame of a holographic reactor core: thousands of glowing amber particles forming a fragmented spherical shell, a dense tilted ring band, thin orbital arcs and a white-hot core, surrounded by a hard-edged HUD frame with thin bars and tick marks. Black background, cinematic bloom, 16:9.
```

Attach the chosen images to the issue. Claude adds them to the app's asset catalog.
